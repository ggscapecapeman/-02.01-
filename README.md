# Симуляция рулетки

Учебный проект (УП 02.01): симуляция европейской рулетки с подсчётом выигрышей и проигрышей.

## Возможности
- ставки на число (выплата 35 к 1) и на цвет (выплата 1 к 1);
- проверка ставки: лимиты 10–1000, не больше баланса;
- подсчёт баланса после каждого раунда;
- итоговый отчёт об игре;
- режимы: интерактивный и автоматический.

## Требования
Python 3.8 или новее. Сторонние библиотеки не нужны.

## Запуск
    python roulette.py
    python roulette.py --auto 20 --seed 1

Параметры: `--auto N`, `--seed S`, `--balance B`, `--name ИМЯ`.

## Файлы
- `roulette.py` — программа;
- `пр5.sbsl` — сценарии форматированного вывода;
- `README.md` — описание проекта.
